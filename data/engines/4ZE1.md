Optimized for 2300 tp 3000 rpm
Runner volume 1L (combined)
Plennum volume 1.5L
Intake runner ID 38mm
Exhaust runner ID 32mm
Exhaust diam 57.2mm
Throttle diam 61mm

## Modifications

- Custom ECU
	- Sequential Injection
	- DBW Throttle & Pedal
	- 36-1 hall effect crank position
	- Cam trigger
- High flow air intake and pod filter
- Oil cooler with thermostat control & PID driven fan (temperature target 85 deg c)


## Reference Data
0.91 Lambda should give best torque
Combustion only occurs between 8.01  and 25.51 air/fuel
Peak flame speed is at lambda 0.9
Idling beyond 0.7 lambda should be hard, but 0.81 lambda idling should work
